# BailianFoundry · 百炼机关 — Releases

Official binary distribution for the Windows PC game **百炼机关 (BailianFoundry)**.

- All downloads are published on the [Releases](../../releases) page.
- Stable update manifest used by the in-game **检查更新** (check for updates) button:

  `https://github.com/BOJUEJUN/bailian-foundry-releases/releases/latest/download/update.json`

- Release assets per version: `BailianFoundry-Setup-<ver>.exe` (installer), `BailianFoundry-<ver>-windows-x64.zip` (flat update package), `update.json` (version manifest), `SHA256SUMS.txt` (checksums).

This repository intentionally contains no game source code — binary releases and release metadata only.
